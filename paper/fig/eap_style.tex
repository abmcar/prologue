% all 15 pairs of the six hues below (grey is the neutral and not tested): normal vision worst 15.6 (stock reth / stock
% reth + reuse), colour-blind worst 7.6 (predict-al / dowse, which are also named beside their points); orange (2.25:1)
% and sky blue (2.31:1) are below 3:1 on white and always come with a dark edge or a line style and a name. predict-al was
%   Prologue                                  blue            #0072B2  solid line     diamond
%   stock reth                                vermillion      #D55E00  dashed line    square
%   stock reth + reuse                        orange          #E69F00  dotted line    triangle
%   stock reth without prewarming             grey            black!55 dash-dot line  circle
%   with only some of Prologue's parts        sky blue        #56B4E9  (ablation rows)
%   predict-al                                bluish green    #009E73  (prediction comparison)
%   dowse                                     reddish purple  #CC79A7  (prediction comparison)
% In black-and-white print every configuration still differs by line style or marker shape and is named in the legend or
% beside its marks. Each colour has four shades: D dark (edges), S saturated, M middle, L light (fills).
% Kinds of time inside a bar: the bar's hue from dark to light (storage-slot wait S, account and code wait M, rest of
% execution L), named once beside the first bar with leader lines.
% Block classes: neutral grey, by marker shape.
%
% MARKS. Data lines 1.2 pt, drawn under the configuration to stress (Prologue), which is drawn last. Bars: fill with a 0.6 pt
% edge in the hue's dark shade. Markers 4.6 pt with a 0.5 pt dark edge. Reference lines 0.6 pt dark grey, named in the
% figure ("stock reth = 1").
% AXES. Left and bottom only, 0.6 pt, ticks outward; grid: light dotted lines across the value axis only.
% LEGEND. One row centred above the plot (above both panels of a two-panel figure), 10 pt between entries; the sample
% carries the colour, the text stays black. Direct labels at the marks where they fit.
